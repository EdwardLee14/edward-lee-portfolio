# Edward Lee — Portfolio

A React resume/portfolio single-page app.

## Run locally

```bash
npm install
npm run dev
```

Then open [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview   # preview production build
```

## Stack

- React 18 + Vite
- No UI framework; custom CSS with CSS variables, Fraunces + DM Sans fonts
